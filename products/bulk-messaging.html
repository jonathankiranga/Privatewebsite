SmartNow solution

Bulk Messaging

Organise contacts and send group-based SMS using a configured gateway.

The Android application documentation describes bulk messaging through Africa’s Talking, with local contact and group management, queued messages and sending history.

Verified capability areas

Contact management

Create contacts and groups, paste recipient lists in bulk and normalise Kenyan phone numbers.

Message workflow

Compose messages for sending or queue them for later processing.

History and visibility

Review send history, status, target, recipient count and gateway response.

Gateway configuration

Configure Africa’s Talking username, API key, sender ID and sandbox or production mode.
